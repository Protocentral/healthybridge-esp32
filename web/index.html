HealthyPi 5 NEXT — ESP32-C3 web installer

Flash the HealthyBridge wireless firmware to the HealthyPi 5 ESP32-C3 directly from your browser — no tools to install. Use Google Chrome or Microsoft Edge on desktop (Web Serial is required; Safari and Firefox are not supported).

  1. Connect the HealthyPi 5 ESP32-C3 USB Type-C port to your computer.
  2. Click Install and select the serial port that appears.
Note: the web installer performs a full install and erases stored Wi-Fi credentials and settings, so you will re-provision over the SoftAP captive portal afterwards. To update the application without losing settings, use the command-line flash.sh --app-only / flash.bat --app-only from the latest release instead.

Firmware source & releases: Protocentral/healthybridge-esp32
